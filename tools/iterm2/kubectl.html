    Wrappers

    This plugin provides 3 wrappers to colorize kubectl output in JSON and YAML using various tools (which must be installed):

    • kj: JSON, colorized with jq.
    • kjx: JSON, colorized with fx.
    • ky: YAML, colorized with yh.
